# NTT 多项式乘法器 — 运行文档

## 环境要求

| 工具 | 最低版本 | 说明 |
|------|---------|------|
| Icarus Verilog | 11.0 | `iverilog` 编译 + `vvp` 仿真 |
| Python | 3.6+ | 生成旋转因子 ROM 和测试向量 |
| GTKWave | 任意版本 | 查看波形（可选） |

## 快速开始

```bash
cd /home/wsluser/temp/ntt_poly_mul/sim

# 步骤 1: 生成 ROM 和测试向量
python3 ../scripts/gen_twiddle.py
python3 ../scripts/golden_model.py

# 步骤 2: 编译
iverilog -g2012 -I ../tb -o ntt_sim.vvp \
  ../rtl/mod_mult.v ../rtl/mod_addsub.v \
  ../rtl/butterfly.v ../rtl/twiddle_rom.v \
  ../rtl/ntt_core.v ../rtl/ntt_top.v \
  ../tb/tb_ntt_top.v

# 步骤 3: 仿真
vvp ntt_sim.vvp

# 步骤 4: 查看波形（可选）
gtkwave wave.vcd
```

## 文件说明

### 生成文件（sim/ 目录）

| 文件 | 说明 |
|------|------|
| `twiddle.hex` | 旋转因子 ROM 初始化文件 (4096×14bit) |
| `tv_a.hex` | 测试输入多项式 A (1024 项) |
| `tv_b.hex` | 测试输入多项式 B (1024 项) |
| `tv_exp.hex` | Python 计算的期望输出 (1024 项) |
| `ntt_sim.vvp` | 编译后的仿真可执行文件 |
| `wave.vcd` | 波形文件 (GTKWave 打开) |

### 编译文件列表

```
rtl/mod_mult.v       Barrett 模乘器
rtl/mod_addsub.v     模加减法器
rtl/butterfly.v      蝶形运算单元 (3级流水线)
rtl/twiddle_rom.v    旋转因子 ROM (组合读)
rtl/ntt_core.v       NTT 核心 FSM + 地址生成
rtl/ntt_top.v        顶层模块 (相位控制 + 存储管理)
tb/tb_ntt_top.v      自检测试平台
```

## 换测试向量

修改 `scripts/golden_model.py` 中的种子即可生成不同的随机向量：

```python
SEED = 42   # 改为其他值生成不同随机向量
```

如果想用自定义数据，替换 `a` 和 `b` 列表：

```python
a = [1, 2, 3, ...]      # 自定义 A
b = [100, 200, ...]     # 自定义 B
```

每次修改后重新运行：

```bash
python3 ../scripts/golden_model.py
iverilog -g2012 -I ../tb -o ntt_sim.vvp \
  ../rtl/mod_mult.v ../rtl/mod_addsub.v \
  ../rtl/butterfly.v ../rtl/twiddle_rom.v \
  ../rtl/ntt_core.v ../rtl/ntt_top.v \
  ../tb/tb_ntt_top.v
vvp ntt_sim.vvp
```

## 查看波形

```bash
gtkwave wave.vcd
```

### 关键信号

**顶层 host 接口：**

| 信号 | 含义 | 位置 |
|------|------|------|
| `host_we` | 写使能 (1=写入, 0=读取) | tb_ntt_top |
| `host_addr` | 访存地址 | tb_ntt_top |
| `host_wdata` | 写入数据 (加载阶段 = RTL 输入) | tb_ntt_top |
| `host_rdata` | 读出数据 (验证阶段 = RTL 输出) | tb_ntt_top |

**蝶形运算内部：**

| 信号 | 含义 | 位置 |
|------|------|------|
| `bf_a`, `bf_b`, `bf_w` | 蝶形输入 | tb_ntt_top.u_dut |
| `bf_res_a`, `bf_res_b` | 蝶形输出 | tb_ntt_top.u_dut |

### 查看输入

1. 打开 `wave.vcd`
2. 拖入 `host_we`、`host_addr`、`host_wdata`
3. 放大到前 ~20 μs
4. `host_we=1` 期间，`host_wdata` 依次为 A[0], A[1], ..., B[0], B[1], ...

### 查看输出

1. 拖入 `host_rdata`
2. 跳转到 ~1.3 ms 附近
3. `host_we=0` 期间，`host_rdata` 依次为 C[0], C[1], ..., C[1023]

## 常见问题

**Q: 提示 `sim/` 目录不存在？**
```bash
mkdir -p /home/wsluser/temp/ntt_poly_mul/sim
```

**Q: 提示 `iverilog: command not found`？**
```bash
sudo apt install iverilog
```

**Q: 提示找不到 hex 文件？**
先运行 `python3 ../scripts/gen_twiddle.py` 和 `python3 ../scripts/golden_model.py` 生成。

**Q: 波形文件太大？**
VCD 文件约几百 MB，查看后可以删除：`rm wave.vcd`
